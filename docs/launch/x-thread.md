## Mechanics

- Line breaks between every logical beat. X rewards dwell time, not density.
- No hashtags. They read as spam on dev X.
- First tweet has no external link in the *text* if you want reach — put it in a reply.
  Trade-off: reach vs click-through. For a dev tool, keep the link in tweet 1.
- Post 09:00–11:00 or 18:00–20:00 in your audience's timezone.
- Quote-tweet yourself at +48h with the best comment or the first patch release.
