# Code of Conduct

## The short form

Be useful. Do not be a hazard.

## Expected

- Critique the code, the design, the tradeoff — never the person.
- Assume competence. Ask what constraint produced the choice before calling it wrong.
- Say "I don't know" when you don't. It costs nothing here.
- Keep review comments about the diff. Long-form disagreement goes to an issue.

## Not tolerated

- Harassment, slurs, sexual attention, or intimidation, in any channel.
- Sustained disruption: reopening settled threads, sealioning, derailing technical threads.
- Publishing someone's private information without permission.
- Bad-faith engagement — filing issues to win an argument rather than to improve the project.

## Enforcement

Report to `conduct@example.com`. Reports are read by the maintainer only.

| Severity | Response |
| --- | --- |
| Correction needed | private note, no record |
| Repeated or hostile | comment deleted, 7-day cooldown |
| Harassment or threats | permanent ban, no appeal |

Enforcement applies in issues, PRs, discussions, and any space where you represent the project.
