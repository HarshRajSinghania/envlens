# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| latest minor | ✅ |
| previous minor | ✅ (critical fixes only) |
| older | ❌ |

## Reporting

Do **not** open a public issue.

- Email: `security@example.com`
- Or use GitHub private advisory: <https://github.com/n5za/envlens/security/advisories/new>

Include: affected version, reproduction, impact, and whether the issue is already public.

## What to expect

| Stage | Target |
| --- | --- |
| Acknowledgement | 48 h |
| Triage + severity (CVSS 3.1) | 5 business days |
| Fix or mitigation for critical | 14 days |
| Public advisory + credit | after fix ships, with your consent |

We credit reporters by name or handle in the advisory unless you ask otherwise.

## Scope

In scope: the code in this repository and its published artifacts.

Out of scope: findings that require a compromised host, missing hardening headers on a docs site, rate limiting on a static endpoint, or reports produced by a scanner with no demonstrated impact.
